C Programming Menu-Driven Console Application

A comprehensive menu-driven application built in C that helps users plan their trips efficiently. The system provides an interactive interface for selecting destinations, attractions, accommodations, and complete travel packages.

  • City Selection: Browse and choose from multiple tourist destinations
  • Attraction Planning: Select popular attractions and points of interest
